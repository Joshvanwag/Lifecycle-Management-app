# Data Model

## Overview

All customer-owned entities are scoped to an `organization_id`. Internal identifiers are immutable UUIDs generated by the database.

## Core Entities (Phase 2)

### Organization

Represents a tenant (customer).

| Field | Notes |
|-------|-------|
| id | UUID, primary key |
| name | Organization display name |
| default_refresh_cycle_years | Default: 7 |
| default_inflation_rate | Default: 0.034 (3.4%) |
| floors_enabled | Default: false |
| industry_type | FK → `industry_types.code` — benchmark cohort (default: `other`) |
| benchmark_participation | Default: **true** — reciprocal opt-in/out for benchmarking |

See `/docs/benchmarking-model.md` for benchmarking architecture.

### Organization Membership

Links users to organizations with roles.

| Field | Notes |
|-------|-------|
| id | UUID |
| organization_id | FK → organizations |
| user_id | FK → auth.users |
| role | owner, admin, member, read_only |

Supports future multi-organization membership per user.

### Location Hierarchy

Flexible, optional hierarchy:

```
Organization → Campus → Building → [Floor] → Physical Location
```

- Floor is optional and disabled by default per organization
- Physical location types are user-definable (not hard-coded enums)
- Spaces and physical locations have many-to-many relationships

### Space

Primary lifecycle object.

| Field | Notes |
|-------|-------|
| id | UUID |
| organization_id | FK |
| name | User-facing name |
| space_type | User-definable type — also used as **benchmark context** (not org cohort) |
| commissioned_date | Initial deployment date |
| refresh_cycle_years | May inherit org default |
| original_cost | Lump-sum or sum of assets |
| planning_status | unplanned, scheduled, deferred, completed |

### Asset

Individual equipment record.

| Field | Notes |
|-------|-------|
| id | UUID (immutable) |
| organization_id | FK |
| space_id | FK → spaces |
| manufacturer | Free text |
| model_number | Same as part number for MVP |
| category | User-definable — also used as **benchmark context** (not org cohort) |
| serial_number | Optional |
| ip_address | Optional |
| mac_address | Optional |
| po_number | Optional |
| install_date | Required |
| cost | Optional (0 valid for lump-sum Spaces) |
| status | active, retired |
| refresh_cycle_years | May override defaults |
| removed_date | Set when retired |

### Forecast Cost Component

Internal financial entity supporting asset-specific and lump-sum forecasting.

| Field | Notes |
|-------|-------|
| id | UUID |
| organization_id | FK |
| space_id | FK |
| asset_id | Optional — null for lump-sum |
| cost_basis | Amount |
| cost_basis_date | Date/year |
| refresh_cycle_years | Lifecycle duration |
| recommended_replacement_year | Calculated |
| inflation_rate | May inherit org default |

### Refresh Event

Historical record of lifecycle changes.

| Field | Notes |
|-------|-------|
| id | UUID |
| space_id | FK |
| type | initial_deployment, full_refresh, partial_refresh, individual_replacement |
| event_date | When refresh occurred |
| description | Human-readable summary |

### Benchmarking Entities (Phase 2 foundation)

Not customer operational data — see `/docs/benchmarking-model.md`.

| Entity | Purpose |
| --- | --- |
| `industry_types` | Extensible industry catalog |
| `benchmark_system_settings` | Internal config (e.g. min contributor threshold = 5) |
| `benchmark_metrics` | Metric catalog with domain and context flags |
| `organization_benchmark_values` | Per-org computed metric values (tenant reads own only) |
| `benchmark_aggregate_metrics` | Anonymous industry aggregates (internal; no direct client access) |

Customer benchmark reads use `get_benchmark_metrics_public()` RPC.

### Import Mapping

`import_mappings` stores reusable column mappings per organization and file workflow (`add`, `full_refresh`, `partial_refresh`). `column_map` is JSON keyed by source header. RLS uses `can_read_organization` / `can_write_organization`.

### Import Jobs

`import_jobs` records completed or failed file imports (workflow, filename, counts). Members can read; writers can insert.

### Admin Audit Events

`admin_audit_events` records invitations, settings changes, and imports. Separate from `refresh_events`.

### Saved Reports

`saved_reports` stores a user-owned report key and filter JSON for the canned Reports page. RLS limits rows to the signed-in user in an organization they can read.

`list_organization_members(organization_id)` returns membership email and role for callers who can read the organization.

## Relationships

- Organization 1:N Spaces, Assets, Locations, import mappings
- Space 1:N Assets (active), N:M Physical Locations
- Space 1:N Refresh Events, Forecast Cost Components
- Asset 1:1 Forecast Cost Component (when itemized)
- Organization 1:N organization_benchmark_values

## Cost Model

Three valid cost scenarios per Space:

- **A.** Fully itemized — Space cost = sum of asset costs
- **B.** Partially itemized — some assets have costs, remainder is lump-sum
- **C.** Completely lump-sum — Space has total cost, assets may show $0

## Identifiers

- Internal: immutable UUID (never row numbers)
- External/customer asset ID: supported in future, not MVP

## Audit vs Lifecycle History

- **Lifecycle/asset history:** equipment changes, refreshes, cost changes
- **Administrative audit:** user invites, role changes, imports, settings changes (`admin_audit_events`)

Kept conceptually separate. Settings shows a recent activity list.
